# 심화과학반 탐구 성찰 설문 (GitHub Pages 배포용)

심화과학반 활동을 돌아보는 성찰 설문 웹 양식입니다. 학생이 브라우저에서
내용을 입력한 뒤, "PDF로 저장(인쇄)" 버튼으로 인쇄 대화상자를 열어
"PDF로 저장"을 선택해 제출용 PDF 파일을 만들 수 있습니다. 이후
"이메일 주소 복사" 버튼으로 제출용 이메일 주소(chemtkim@naver.com)를
복사해 PDF 파일을 첨부해 보내면 됩니다.

## GitHub Pages로 배포하는 방법

1. GitHub에서 새 저장소(Repository)를 만듭니다. (예: `reflection-survey`)
2. 이 폴더의 내용을 저장소에 업로드합니다(웹 UI로 파일 끌어다 놓기 또는 `git push`).
3. 저장소의 **Settings → Pages** 메뉴에서 **Branch: main / (root)** 를 선택하고 저장합니다.
4. 잠시 후 `https://<사용자명>.github.io/<저장소이름>/` 주소로 설문지에 접속할 수 있습니다.
5. 학생들에게 이 주소를 공유하면, 새 탭에서 열려 인쇄(PDF 저장)와 이메일 주소 복사가
   Claude 아티팩트 미리보기보다 안정적으로 동작합니다.

## 파일 구성

- `index.html` — 설문지 전체(HTML/CSS/JS 한 파일에 포함, 외부 라이브러리 없음)

## 참고

- 이 페이지는 입력값을 학생의 브라우저(localStorage)에만 임시 저장합니다. 서버로 전송되지 않으므로
  꼭 "PDF로 저장" 후 이메일로 제출해야 합니다.
